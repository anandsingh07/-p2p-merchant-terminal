# BharatSwap Merchant Terminal: Advanced P2P Integration

A high-performance Virtual Point of Sale (vPOS) terminal engineered to interface with the P2P.me protocol. This terminal facilitates secure, decentralized USDC settlements for retail merchants using the Base Sepolia blockchain.

## Technical Core and P2P.me SDK Implementation

The terminal architecture is built around a heavy integration of the @p2pdotme/sdk, leveraging the protocol's modular facets to ensure transaction integrity and real-time liquidity management.

### 1. Modular Diamond Architecture (EIP-2535)
The terminal utilizes the SDK to interface with the P2P Diamond Proxy. By targeting the official Diamond address (0xce868398fdadca368eac203222874d6888532ae2), the terminal executes cross-facet calls that handle everything from price discovery to order registration. This allows for a lightweight frontend that inherits the security and upgradeability of the underlying protocol.

### 2. Real-Time Liquidity and Price Synthesis
Instead of relying on centralized exchange rates, the terminal uses the SDK's Price Engine to synthesize live on-chain data. The getPriceConfig and getReputationPerUsdcLimit methods are used to determine the exact INR/USDC spread, ensuring merchants receive the most competitive rates available in the P2P liquidity pool at the moment of payment.

### 3. Automated Protocol Fee Engine
Every transaction generated by the terminal is pre-processed through the SDK's OrdersClient to fetch current FeeConfig metrics. This ensures that the generated EIP-681 QR codes account for protocol-level small-order thresholds and fixed fees, preventing transaction failures during the settlement phase.

### 4. Encrypted P2P Payment Rails
The terminal implements the SDK's cryptographic modules to manage relay identities and public keys. This ensures that payment metadata remains private and encrypted, accessible only to the merchant and the verified settlement provider.

## Upcoming Feature Roadmap

The following modules are currently in development to further enhance the merchant experience:

### P2P Merchant Sell (Offramp) Module
A comprehensive peer-to-peer offramp engine that will allow merchants to convert their USDC earnings directly into INR bank accounts. This module will utilize the SDK's escrow logic to lock USDC and verify UPI/IMPS bank transfers, providing a seamless bridge between crypto earnings and fiat liquidity.

### Merchant Reputation and Limit Scaling
Integration with the SDK's Reputation Manager facet to allow high-volume merchants to increase their daily transaction limits based on their successful settlement history.

### Integrated Dispute Resolution
A dedicated interface for managing P2P disputes directly within the terminal, leveraging the SDK's raiseDispute and watchEvents capabilities.

## Local Development Setup

### 1. Repository Initialization
git clone https://github.com/anandsingh07/-p2p-merchant-terminal.git
cd -p2p-merchant-terminal

### 2. Dependency Management
npm install

### 3. Security Configuration
The terminal requires a valid Thirdweb Client ID to manage wallet connections. Create a .env.local file:
NEXT_PUBLIC_THIRDWEB_CLIENT_ID=your_client_id_here

### 4. Development Server
npm run dev
